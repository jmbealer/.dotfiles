# Hosts

Machine-specific NixOS configurations. Each subdirectory maps to one physical
machine and its `default.nix` is imported by `flake.nix` as a
`nixosConfigurations.<name>` entry.

## Conventions

- Directory name matches the hostname (`networking.hostName`).
- `default.nix` — machine-specific system config (bootloader, kernel params,
  GPU drivers, machine-specific services, theming).
- `hardware.nix` — generated by `nixos-generate-config`; do not hand-edit
  (regenerate instead).
- `packages.nix` — machine-wide `environment.systemPackages`.

## Shared baseline

`common/` holds settings applied to **every** machine (nix daemon settings,
locale, audio, sysctl, user definitions), so a host directory only contains
what is actually unique to that machine.

## Adding a machine

1. `mkdir hosts/<hostname>`
2. Generate hardware config:
   `sudo nixos-generate-config --show-hardware-config > hosts/<hostname>/hardware.nix`
3. Create `hosts/<hostname>/default.nix` importing `../common/default.nix` and `./hardware.nix`
4. Add a `nixosConfigurations.<hostname>` entry to `flake.nix`
5. Rebuild: `sudo nixos-rebuild switch --flake .#<hostname>`
