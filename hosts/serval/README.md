# Host: serval

System76 Serval WS laptop — the primary (and currently only) machine in this flake.
Hostname: `serval`.

## Hardware

- Vendor: System76, Model: Serval WS (serw12)
- CPU: AMD (kvm-amd), CachyOS kernel (`linuxPackages_cachyos-gcc`)
- GPU: NVIDIA (open kernel modules, modesetting enabled)
- Storage: dual NVMe (`nvme0n1`, `nvme1n1`), Btrfs with subvolumes
  (`@root`, `@home`, `@nix`, `@log`, `@persist`, `@games`, `@vms`, `@snapshots`)
- Boot: systemd-boot on a vfat EFI partition

## Files

- `default.nix` — boot params, resume device, NVIDIA, services (earlyoom, scx,
  keyd, nextdns, pipewire, displayManager.ly), hardware, networking, sops,
  theming (stylix), fonts, systemd services.
- `hardware.nix` — generated by `nixos-generate-config`; regenerate instead of
  editing by hand.
- `packages.nix` — system-wide packages (dev tools, CLI utils, Hyprland stack,
  browsers, GNOME/GTK integration).

## Storage

`fileSystems`, `swapDevices` and `boot.resumeDevice` live in
`hardware.nix` / `default.nix` (the classic NixOS way). Disko was
evaluated and rejected for this machine:

- The Btrfs "NIXOS" filesystem spans **both** NVMe drives
  (multi-device Btrfs), which Disko cannot express.
- This is not a fresh install — the disks are already provisioned, so
  there is nothing for Disko to do.
- The abandoned attempt lives in `deprecated/misc/disks.nix` for
  reference.

## Notes

- The `keyboard-backlight` systemd service sets the System76 keyboard backlight
  to red at 50% on boot.
- Resume device and swap UUIDs are machine-specific; keep them here, not in
  `hosts/common/`.
